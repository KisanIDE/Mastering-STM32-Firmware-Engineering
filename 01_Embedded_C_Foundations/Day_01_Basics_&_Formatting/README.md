# Lesson 1: C I/O Mechanics & Escape Sequences

## Overview
This project demonstrates the core fundamentals of standard I/O in C programming using the printf function. It focuses on how the compiler interprets string literals, format boundaries, and specialized escape characters.

## Key Concepts Mastered
* String Literal Formatting: Displaying special characters without breaking compiler syntax.
* Double Quote Escape (\"): Embedding literal quotation marks inside an active string.
* Backslash Escape (\\): Displaying windows directory paths by escaping the backslash itself.
* Code Documentation: Using standard single-line (//) and multi-line (/* */) comments.
